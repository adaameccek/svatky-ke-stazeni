# Svátky

Appka na jmeniny pro Android s widgetem, měsíčním kalendářem, hledáním jmen a ranním oznámením.

**Vyzkoušet na webu:** https://svatky.adamhorak.cz

## Stažení pro Android

Nejnovější verze je v sekci [Releases](https://github.com/adaameccek/svatky-ke-stazeni/releases/latest) jako soubor `svatky.apk`. Stáhni ho v telefonu, otevři a povol instalaci z tohoto zdroje.

## Kód

Zdrojový kód je tu k nahlédnutí a ke stažení. Úpravy dělá jen autor, navržené změny (pull requesty) se nepřijímají.
